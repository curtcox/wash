# Text-processing pipeline toolbox

Single source of truth: **`tools.toml`**. This file and the install manifests are generated by `generate.py` — edit the TOML, then re-run `python3 generate.py`.

## How to read this

- **role** — what the tool does (primary picker axis).
- **group** — redundancy cluster: pick **at most one** tool per group for a given job. The picker should prefer lower install cost within a group.
- **avail** — `posix` (preinstalled) · `pkg` (one brew/apt install) · `heavy` (large dep / model download).
- **★** marks the curated **baseline** set (install once; covers most pipelines).
- **when** — when to reach for it vs. its group-mates.

## Full index by role

### aggregate

- ★ **datamash** [one package, group: `unique`] — Group-by, sum/mean/median/stdev, crosstab, transpose on columnar text — without writing awk. First reach for quick stats on TSV.
  - brew: `datamash` · apt: `datamash`

### binary-view

- ★ **xxd / hexdump / od** [preinstalled, group: `hexdump`] — Hex view of bytes; xxd also does the reverse (xxd -r) to rebuild binary from hex. od/hexdump are POSIX variants.
  - brew: `vim` · apt: `xxd`
- **hexyl** [one package, group: `hexdump`] — Colored, readable hex viewer. Display nicety over xxd.
  - brew: `hexyl`

### char-translate

- **expand / unexpand** [preinstalled, group: `whitespace`] — Convert between tabs and spaces.
  - brew: `coreutils` · apt: `coreutils`
- **fold / fmt / pr** [preinstalled, group: `wrap`] — Wrap/reflow/paginate plain text. fold = hard wrap at width; fmt = reflow paragraphs; pr = paginate with headers.
  - brew: `coreutils` · apt: `coreutils`
- **rev** [preinstalled, group: `unique`] — Reverse characters per line.
  - brew: `util-linux` · apt: `util-linux`
- ★ **tr** [preinstalled, group: `unique`] — Translate/delete/squeeze characters. Casing, deleting char classes, squeezing whitespace.
  - brew: `coreutils` · apt: `coreutils`

### count

- ★ **wc** [preinstalled, group: `unique`] — Count lines/words/bytes/chars.
  - brew: `coreutils` · apt: `coreutils`

### csv-query

- **csvkit** [one package, group: `tabular-suite`] — Python suite: csvcut/csvgrep/csvjson/csvsql/in2csv (Excel→CSV!). Reach for in2csv (format ingestion) and csvsql (SQL on CSV). Slower than qsv/mlr on big data.
  - brew: `csvkit`
- **csvq** [one package, group: `tabular-sql`] — Run SQL directly against CSV/TSV files (SELECT/JOIN/UPDATE). Use when the transform is naturally relational.
  - brew: `csvq`
- **dsq** [one package, group: `tabular-sql`] — SQL over CSV/JSON/Parquet/etc via an embedded engine. Like csvq but multi-format input. Pick one SQL-on-files tool.
  - brew: `dsq`
- ★ **miller (mlr)** [one package, group: `tabular-engine`] — awk-like but format-aware (CSV/TSV/JSON/pprint) with named fields, joins, stats, reshaping. The most general 'structured awk'. First reach for CSV transforms.
  - brew: `miller` · apt: `miller`
- **q** [one package, group: `tabular-sql`] — SQL on delimited text (python). Mature but slower; sqlite3 .import or dsq often preferable now.
  - brew: `q`
- **qsv** [one package, group: `tabular-fast`] — Very fast CSV toolkit (descendant of xsv) — select/join/stats/dedup/sample/index on big files. Pick qsv over xsv for new use; performance-first.
  - brew: `qsv`
- **xsv** [one package, group: `tabular-fast`] — Original fast CSV swiss-army. qsv supersedes it; use xsv only if already present.
  - brew: `xsv`

### dedup

- ★ **uniq** [preinstalled, group: `dedup`] — Collapse/count ADJACENT duplicates — pipe sorted input. For unsorted-dedup-preserving-order use awk '!seen[$0]++'.
  - brew: `coreutils` · apt: `coreutils`

### diff

- **comb (comm)** [preinstalled, group: `set-compare`] — Line-set comparison of two SORTED files (common / only-in-A / only-in-B). Set algebra, not edit diff.
  - brew: `coreutils` · apt: `coreutils`
- ★ **diff** [preinstalled, group: `diff`] — Line diffs; unified/context. For word-level use wdiff/dwdiff; for prettier code diffs use delta.
  - brew: `diffutils` · apt: `diffutils`
- **delta** [one package, group: `diff-display`] — Syntax-highlighted pager for git/diff output. Display only — pair with diff/git.
  - brew: `git-delta` · apt: `git-delta`
- **wdiff / dwdiff** [one package, group: `diff-word`] — Word- or character-level diffs of prose. dwdiff lets you define delimiters.
  - brew: `wdiff` · apt: `wdiff`

### dispatch

- ★ **xargs** [preinstalled, group: `dispatch`] — Turn stdin into args for a command. Use -0 with find -print0. For concurrency/complex output, prefer GNU parallel.
  - brew: `findutils` · apt: `findutils`
- ★ **parallel (GNU parallel)** [one package, group: `dispatch`] — Run a command across many inputs concurrently with controlled jobs. More features than xargs -P (grouped output, retries, remote). For simple cases xargs suffices.
  - brew: `parallel` · apt: `parallel`

### encoding-convert

- **base64 / base32** [preinstalled, group: `baseN`] — Encode/decode binary↔text. base64 -d to decode.
  - brew: `coreutils` · apt: `coreutils`
- ★ **iconv** [preinstalled, group: `charset`] — Convert character encodings (e.g. latin1→utf8). For format-guessing reencode use recode.
  - brew: `libiconv` · apt: `libc-bin`
- ★ **dos2unix / unix2dos** [one package, group: `line-endings`] — Fix CRLF/LF line endings. Quick and purpose-built vs a tr/sed incantation.
  - brew: `dos2unix` · apt: `dos2unix`
- **recode** [one package, group: `charset`] — Higher-level charset/surface recoding (incl. HTML entities). iconv for plain charset, recode for entity/surface tricks.
  - brew: `recode` · apt: `recode`

### extract

- **strings** [preinstalled, group: `unique`] — Pull printable strings out of binary files.
  - brew: `binutils` · apt: `binutils`
- **catdoc / antiword / unrtf / docx2txt** [one package, group: `office-extract`] — Legacy office extraction: catdoc(.doc/.xls), antiword(.doc), unrtf(.rtf), docx2txt(.docx). For modern formats pandoc or libreoffice is more robust.
  - brew: `catdoc` · apt: `catdoc`
- **mutool (mupdf)** [one package, group: `pdf-extract`] — Fast PDF text/draw/extract and conversion. Alternative engine to poppler when output quality/structure differs.
  - brew: `mupdf-tools` · apt: `mupdf-tools`
- ★ **pdftotext (poppler)** [one package, group: `pdf-extract`] — Extract the text layer from PDFs (also pdftohtml, pdfimages, pdfinfo in poppler). Use FIRST; only OCR if there's no text layer.
  - brew: `poppler` · apt: `poppler-utils`

### field-extract

- ★ **awk (gawk)** [preinstalled, group: `awk`] — Field-based extraction and per-line compute. mac ships BSD awk; install gawk for GNU extensions. The workhorse for column math, group-by sums, reformatting.
  - brew: `gawk` · apt: `gawk`
- ★ **column** [preinstalled, group: `align`] — Align columns for display (column -t). Presentation, not extraction.
  - brew: `util-linux` · apt: `bsdmainutils`
- ★ **cut** [preinstalled, group: `cut`] — Simple byte/char/field slicing on a fixed delimiter. Fast and ubiquitous. For multi-char delimiters, regex fields, or reordering, use awk/choose/hck.
  - brew: `coreutils` · apt: `coreutils`
- ★ **join** [preinstalled, group: `relational`] — Relational join of two SORTED files on a key. For unsorted/complex joins prefer csvq/miller/sqlite3.
  - brew: `coreutils` · apt: `coreutils`
- ★ **paste** [preinstalled, group: `merge-lines`] — Merge lines side-by-side / join multiple files column-wise. Inverse-ish of cut.
  - brew: `coreutils` · apt: `coreutils`
- **choose** [one package, group: `cut`] — cut/awk hybrid with negative indexing and ranges (e.g. choose 0 -1). Nicer ergonomics than cut for ad-hoc field picking.
  - brew: `choose-rust`
- **frawk** [one package, group: `awk`] — awk-compatible but compiled/parallel — much faster on large files. Use when gawk is the bottleneck and the script is awk-expressible.
  - cargo install frawk
- **goawk** [one package, group: `awk`] — Single-binary POSIX awk with CSV mode. Handy for embedding/CI where you want awk without a system dependency.
  - go install / release binary
- **hck** [one package, group: `cut`] — cut alternative with regex delimiters and field reordering, fast. Use when cut's single-char delimiter is too limiting.
  - cargo install hck
- **teip** [one package, group: `cut`] — Masks selected fields, pipes ONLY those through another command, then splices results back. Unique: edit part of a line with an external tool without touching the rest.
  - brew: `teip`

### find-files

- ★ **find** [preinstalled, group: `find`] — Canonical file finder with predicates/-exec. BSD vs GNU differ. For fast interactive use + gitignore, prefer fd.
  - brew: `findutils` · apt: `findutils`
- ★ **fd** [one package, group: `find`] — Fast, ergonomic find: regex by default, gitignore-aware, parallel -x. apt installs binary as fdfind. First choice interactively.
  - brew: `fd` · apt: `fd-find`

### format-convert

- **html2text / html2markdown** [one package, group: `html-to-text`] — Strip HTML to readable text/markdown. For full doc conversion prefer pandoc; for scraping fields prefer pup.
  - brew: `html2text` · apt: `html2text`
- ★ **jc** [one package, group: `command-to-json`] — Parses output of ~100 commands (ls, ps, dig, ifconfig, /etc files) and many formats INTO JSON so you can pipe to jq. The bridge from unstructured CLI output to structured.
  - brew: `jc`
- ★ **pandoc** [one package, group: `doc-convert`] — Universal document converter: md/html/docx/rst/latex/epub ↔ each other. First reach for any doc-format translation.
  - brew: `pandoc` · apt: `pandoc`
- **libreoffice (--headless)** [heavy / model, group: `office-convert`] — Headless convert almost any office doc (doc/xls/ppt/odt) to pdf/txt/csv. Heavy but the most faithful office converter.
  - brew: `libreoffice` · apt: `libreoffice`

### html-query

### json-build

### line-search

- ★ **ripgrep (rg)** [one package, group: `line-search`] — Fastest recursive search; respects .gitignore; great defaults. First choice for searching codebases/dir trees. Has --replace for in-stream substitution.

- **the_silver_searcher (ag)** [one package, group: `line-search`] — Predecessor to rg with similar ergonomics. Pick rg over ag for new setups; ag only if already standardized on it.
